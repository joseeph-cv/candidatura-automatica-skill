# Ficha do candidato (modelo)

Copie, preencha e mande para a IA junto com o currículo. Exemplo com uma pessoa fictícia.

| Pergunta | Resposta |
|---|---|
| Nome | Mariana Lopes Andrade |
| Cargo(s) desejado(s) | Analista de Dados Júnior; Analista de BI Júnior |
| Nível | Júnior (aceita estágio? Não) |
| Pretensão CLT | 4500 |
| Aceita PJ? Valor | Sim, 5800 |
| Cidades | São Paulo e Grande SP |
| Modalidade | Presencial, híbrido ou remoto |
| Aceita mudança de cidade? | Não |
| Inglês | Intermediário (B1) |
| Outros idiomas | Espanhol básico |
| Horário disponível | Comercial |
| Formação e previsão de conclusão | Bacharelado em Estatística, concluído em 2025 |
| Ferramentas (anos de uso no trabalho) | Excel 3, SQL 2, Power BI 2, Python 1 |
| CNH | Não |
| Disponível para viajar? | Sim, eventualmente |
| Salário atual (se perguntarem) | Prefiro informar na entrevista |
| Aceites de privacidade (LGPD) obrigatórios | Pode aceitar |
| Autodeclarações (raça, gênero, PcD) | Não preencher, deixar como pendente |
| Quantas candidaturas nesta rodada | 30 (15 LinkedIn + 15 Gupy) |
| Vagas que NÃO quer | Call center, vendas externas |

Quanto mais completa a ficha, menos a IA precisa parar para perguntar.
